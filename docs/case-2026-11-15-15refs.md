## 给插件的结论

- 「同角色作品数」是强证据但不能单独排序（多产角色画师会霸榜）；`chart_top`（全站前 10）×1.3 与名次衰减锚点才是把 hews/0haribo0 这类拉开的关键。
- 多张参考图跨角色时，多角色锚点（0.18.0）明显优于单角色：只锚 Firefly 时 hews 排第 3–4，加入 Kafka 后并列第 1。
- 服装专精 tag（latex/和服/泳装）只适合做补充锚点，单独锚定会把「服装专精画师」排上来，必须回到六项清单整体复核。

## 第二轮修订（0.23.0）：改为画风优先

用户指出：**相近画风搜索不应该把具体角色当作判断基点**——要的是「人物类型 + 色调 + 画面风格」都贴近，而不是角色相同。旧方案（0.17–0.18）用 `character` 当锚点有两个问题：

1. **漏掉同手画师**：`nyantcha`、`merunyaa` 这类「手和参考图高度像、但没画过 Firefly/Kafka」的画师，角色模式永远看不到；
2. **奖励角色多产画师**：同角色帖子越多排名越高，容易把「画过这个角色」误当成「画得像」。

0.23.0 的做法：默认 `mode="style"`，完全不使用角色 tag；`style_tags`（画风/线/上色/材质）+ `subject_tags`（体型/肤色/脸/表情等「人物类型」，不是身份）+ `genre_tags`（场景）；锚点 = 第一个 style tag + 第一个 subject tag，pair = 画风×画风 / 画风×人物类型 / 画风×题材 / 人物类型×题材，核验 = `画师×锚点画风 tag`（`style_posts`）。

复跑结果（同一批 15 张图，`style_tags="shiny_skin, sweat, oiled_skin"`、`subject_tags="huge_breasts, dark_nipples, pale_skin"`、`genre_tags="sex, hetero, cum"`）：

| 排序 | 画师 | 说明 |
|---|---|---|
| 1 | `nyantcha` | 97.6 分：全站前 10 + 画风核验 27-97 帖；油亮苍白肉体、深色乳晕最贴 R02/R14 |
| 2 | `hews` | 43.1 分：**画风模式仍然排第 2**（`style_posts` 96），脸/线/构图最贴 R03/R07——不是靠角色进来的 |
| 3 | `mochirong` | 38.4：白底/白毛/冷调 |
| 4 | `merunyaa` | 35.2：油亮 + 深乳晕，但线条偏厚 |
| 5 | `asou_(asabu202)` / `piutahayo` / `elocca` | 油亮但脸/线不够像 |

目视核对后：`nyantcha` 与 `merunyaa` 补「油亮/深乳晕/肉体」，`hews` 补「脸/线/构图」，`mochirong`/`mignon` 补「白底/冷调」。角色模式里的 `0haribo0`/`harin_05`/`greem_bang` 仍然有效（背身/苍白肉体/重油光），但它们不再作为判断基点，只作为同手候选。

## 修订结论（画风优先）

- 主串：`1.0::artist:hews::, 0.55::artist:nyantcha::, 0.35::artist:mochirong::`
- 油亮重口版：`1.0::artist:hews::, 0.6::artist:merunyaa::, 0.35::artist:nyantcha::`
- 背身/苍白版：`1.0::artist:hews::, 0.5::artist:0haribo0::, 0.35::artist:harin_05::`
- 脸部特写版：`1.0::artist:hews::, 0.45::artist:0haribo0::, 0.3::artist:mignon::`
- 极简：`1.0::artist:hews::, 0.5::artist:nyantcha::`

调参：hews 保 1.0（脸/线/构图）；想更油 → 升 nyantcha/merunyaa；想更白更冷 → mochirong/mignon；想更「厚」→ greem_bang。

## 修订后的插件结论

- **角色只能当「补充证据」，不能当排序基点**：同角色≠同画风；默认 style 模式让 nyantcha 这类同手画师能被看到。
- `subject_tags` 解决「人物也要像」而不引入身份：体型/肤色/脸/表情是「被画的人」，不是「哪个角色」。
- 画风核验（`画师×锚点画风 tag`）比同角色核验更贴近目标：它衡量「是否画这种手」，与角色无关。
- 多轮时每轮换一个 style 主锚点（shiny_skin / sweat / latex…），同名画师跨轮出现优先；最后才写权重。
